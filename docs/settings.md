# 设置与用户配置清单

打开 Web 的「设置」，可以集中管理数据接入、模型、OSS 事件归档、回测费用和通知。基础安装使用本地 SQLite；不填写模型、OSS 或通知凭据也可以导入 CSV、查询行情和运行回测。

| 要使用的功能 | 需要准备什么 | 配置位置 |
| --- | --- | --- |
| 自有 CSV 行情 | 符合约定格式的标的与 K 线 CSV | 设置 → 数据接入选择手动 CSV；按[导入说明](data-import.md)执行 CLI |
| Tushare 官方行情 API | 自己的 Tushare token，以及相应数据权限和调用额度 | 设置 → 数据接入 |
| 自有 HTTP 数据服务 | 接口根地址，可选 token；服务需实现约定协议 | 设置 → 数据接入；见[接口契约](data-provider.md) |
| 自定义源码数据源扩展 | 已编译注册的 provider；地址与 token 按该扩展的约定填写 | 设置 → 数据接入中选择注册名称 |
| AI 流水线 | OpenAI 兼容或 Anthropic 接口地址、模型名、API key | 设置 → 模型与助手 |
| Agent 助手 | 先安装 Agent Runtime，再配置模型、上下文/输出上限并检查连接 | 安装器 `--with-agent`；设置 → 模型与助手 |
| OSS 事件归档 | Endpoint、Region、Bucket、对象前缀及 AccessKey | 设置 → OSS 事件归档 |
| 回测交易成本 | 佣金率、最低佣金、卖出印花税率与滑点假设 | 设置 → 回测 |
| 邮件通知 | SMTP 服务器、端口、账号、密码/授权码、发件人、默认收件人 | 设置 → 通知 |
| 飞书机器人通知 | 自己的机器人 webhook，可选签名密钥 | 设置 → 通知 |
| 外部 MCP 客户端 | 启用 MCP 扩展，使用其独立 token | 安装器 `--with-mcp`；设置 → 安全与部署查看指引 |

## 数据接入

可选择手动 CSV、Tushare 官方 API、自有 HTTP 接口或已注册的源码扩展。没有内置免费外站采集器；HTTP 选项连接的是你提供的数据服务。服务是否免费及其数据授权由你所使用的接口决定。

行情设置包括首次回补年数、采集并发、每分钟请求上限、是否包含 ETF，以及每日自动同步开关和执行时刻。时刻按「安全与部署」显示的服务时区计算。手动 CSV 模式不运行自动行情采集。

- 回补年数：1–50；采集并发：1–32。
- 每分钟请求上限：0–60000，0 表示不限制。请按上游实际额度填写。
- 自有 HTTP 服务提供 `GET <base_url>/instruments` 和 `GET <base_url>/bars`，使用 `cursor` 和 `limit=1000` 分页，返回 `{ "items": [], "next_cursor": "" }`。行情请求还携带 `code`、`period`、`start`、`end`。日期使用 `YYYY-MM-DD`；完整字段、校验与限制见[接口契约](data-provider.md)。
- 自有 HTTP 的可选 token 放在 `Authorization: Bearer ...` 请求头，不应放进 URL。接口地址不能带账号、密码、查询参数或片段；请求不跟随重定向。
- 已保存 token 时，修改 HTTP 地址必须同时明确替换或清除 token，防止旧凭据被发往另一个服务。源码扩展仍需遵循其自身接口协议，不能默认认为它也实现了通用 HTTP 契约。
- Tushare 和 HTTP/扩展 token 分别保存，切换来源不会自动删除另一个来源的凭据。

「检查已保存的数据源」只测试已保存配置：HTTP 读取首个标的目录页，Tushare 读取一条 `stock_basic`。成功不代表具备 ETF、其他数据集的访问权限或足够的全量采集额度。先保存，再检查。查询不会自动补齐行情；实际采集任务和覆盖度仍在「数据同步」页面。

资讯数据源扩展位于同一设置组下方，控制已安装资讯扩展的启停、轮询间隔和立即采集。行情 provider 的配置不会安装资讯采集器。

## 凭据、保存与生效

数据源 token 和 OSS AccessKey 不回显。页面只展示是否已配置，凭据默认选择「保留现有凭据」；只有明确选择「替换」并输入新值，或选择「清除」，才会修改它。切换回保留/清除时，不会提交先前输入的替换值。

数据接入与 OSS 各自独立保存，不会覆盖另一组未提交的表单。保存带配置版本；另一页面已修改配置时，重新读取并检查差异后再保存。数据接入与 OSS 配置保存在 API 数据目录的 `settings/integrations.yaml`，文件权限为 `0600`、目录权限为 `0700`，进程重启后仍保留；备份持久化数据时应一并保留并按含凭据的私有资料管理。模型、资讯和通知设置仍保存在数据库中。

保存会更新下一次采集和调度，正在运行的任务继续使用其已有配置快照。归档运行中不能更改归档配置，请等待完成后再保存。部署若使用 `--no-background`，定时采集和归档不会执行；页面会显示该状态，保存设置不会绕过这个启动开关。手动归档仍有真实清理效果。

模型和通知继续使用各自的保存按钮。模型地址、默认模型和密钥供流水线与助手共用；修改后需要重新检查模型连接。助手配置中的密钥撤销也会影响使用同一 provider 的流水线。

## OSS 事件归档会清理本地数据

此功能仅归档过期的已终态事件、执行轨迹和 AI 结果：`pipeline_event`、`pipeline_event_trace`、`pipeline_ai_result`。处理中事件仍留在本地。它不是行情同步、资讯备份、全库备份或自动恢复功能。

配置本地保留天数和每日执行时刻后，可以开启定时归档。手动按钮明确标为「立即归档并清理本地过期事件」，点击后需要再次确认。已保存且完整的 OSS 配置、没有正在运行的归档任务时才能执行。

归档将数据压缩为 JSONL.GZ，上传事件、轨迹、AI 结果和清单，完整读回验证后才删除对应已归档且未改变的本地记录。新批次使用 `prefix/event/dt=YYYY-MM-DD/batch=<snapshot-sha256>/`；对象名包含内容 SHA，清单使用 `schema_version=2`。旧目录存档保持原样。应用没有自动恢复冷数据的界面。

- 本地保留天数：1–36500；每批事件数：1–2000；批次间隔：0–60000 毫秒。
- Endpoint 可以填写裸主机名，服务端会规范为 HTTPS。对象前缀可使用 `quant4dad/`，不能包含重复斜杠、点路径段或上级目录引用。
- 已保存 OSS 凭据时，修改 Endpoint 必须为 AccessKey ID 和 AccessKey Secret 都选择替换或清除。只修改 Bucket、Region 或前缀不要求重新输入凭据。
- 关闭定时归档后，可以保留 OSS 配置并在明确确认后手动归档。
- 「检查已保存的 OSS 连接」仅发起 `GetBucketInfo` 读取请求，不上传或删除对象。它需要读取桶信息的权限；成功不能证明拥有归档所需的 `PutObject` 和 `GetObject` 权限。

## 回测和通知

费用模型可新增、编辑、删除及设为默认；默认模型不能直接删除。回测未指定模型时使用默认模型。页面的费率以百分比显示并转换为接口的小数费率，滑点使用 bps。参数是回测假设，请按实际需求配置；零费用也可以保存。

费用值必须有限且非负；费率不得超过 100%，滑点不得超过 10000 bps。回测并发 `backtest.worker_pool` 是进程启动配置，设置页只显示当前值，调整后需重启 API。

SMTP 密码/授权码和飞书签名密钥留空会保留原值。通知设置不会自行发送消息；实际发送由你启用的流水线通知节点触发。

## 保留在安装阶段的配置

「安全与部署」集中展示以下项目的脱敏状态及修改指引，不在浏览器中即时修改进程和容器：

- 数据库后端/DSN、持久化目录、端口和绑定地址、服务连接地址、可信代理、服务时区。
- Agent 与 MCP 容器是否部署；内部控制 token、签名密钥、profile 和镜像标识由安装器维护。
- 登录 token 与外部 MCP token。默认位于安装状态目录的 `config/login-token`、`config/mcp-token`，两者用途不同；MCP token 授权全部业务工具及写操作。
- 回测并发和后台任务总开关。

这些配置的轮换或调整需修改对应私有配置并重启相关服务。轮换 MCP token 时，API 与 MCP 代理必须一致；只编辑某一个 token 文件不会自动刷新所有进程。不要将数据库、凭据、运行配置、日志中的敏感内容或模型密钥提交到仓库。具体安装命令和自定义状态目录见[部署说明](deployment.md)。
